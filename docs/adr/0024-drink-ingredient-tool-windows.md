# ADR-0024: 음료 제조실 재료는 재료별 작업 창에서 넣는다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-044, SFR-046, SFR-047

## 맥락

음료 제조실 선반의 재료 칸은 클릭 1회로 바로 투입(시럽·청·연유·티백)하거나, 누르고 있는 동안 붓는(우유·탄산수) 방식이었다. 재료를 넣는 동작이 아이콘 클릭뿐이라 실제로 음료를 만드는 느낌이 약했다.
사용자 요청 (2026-11-12): "시럽 넣을 때는 시럽 펌핑하는 모달창, 티백을 할 때는 티백 창, 우유나 탄산수를 넣을 때는 그 창으로 이동하도록. 예쁜 그림체로."

## 결정

선반 재료를 누르면 음료 제조실 위에 재료 작업 창(`IngredientToolScreen`, 창 하나 재사용)이 열린다. 저울 위에 잔이 없으면 열지 않고 '컵을 먼저 올려 주세요' 안내를 띄운다.

| 재료 | 도구 그림 | 조작 |
|---|---|---|
| 시럽, 연유 | 펌프 병 | 클릭 1회 = 펌프 1회 (`syrupPerClick`) |
| 청 | 청 병 + 숟가락 | 클릭 1회 = 한 숟가락 (`syrupPerClick`) |
| 티백 | 티백 상자 | 클릭 1회 = 티백 1개, 잔에 티백 덧그림 |
| 우유, 탄산수 | 우유 팩 / 탄산수 병 | 누르고 있는 동안 붓기 (`pourPerSecond`) |

창 오른쪽에는 저울 위 잔(큰 컵 그림)과 무게를 보여 주고, 투입·붓기 순간 줄기 애니메이션을 보여 준다. 투입량 계산은 기존 `DrinkStation.AddIngredient` / `Pour` 를 그대로 쓴다. 그림은 정수기·샷 내리기 창과 같은 일러스트 스타일이다 (Art/UI/DrinkTools).

연유와 청은 사용자가 따로 말하지 않아, 연유는 펌프 병, 청은 숟가락으로 정했다.

## 검토한 대안

- 재료마다 다른 창(프리팹) 4개: 구성이 같아 창 하나에서 도구 그림만 바꾸는 쪽이 간단하다.
- 선반에서 바로 투입(기존): 사용자가 작업 창 방식을 원했다.

## 결과

- 재료 1회 투입에 클릭이 한 번 더 든다 (창 열기). 같은 재료를 여러 번 넣을 때는 창 안에서 계속 누르면 된다.
- 쉐이크 제조실 선반은 이번 결정에 포함하지 않는다.

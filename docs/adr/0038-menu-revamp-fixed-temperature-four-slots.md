# ADR-0038: 메뉴 개편, 온도 고정 음료, 손 칸 4개, 재료별 작업 창 그림

- 상태: 대체됨 (ADR-0041 콜드브루 ICE 고정 부분)
- 날짜: 2026-11-17
- 관련 명세: SFR-010, SFR-021, SFR-026, SFR-027, SFR-044~054

## 맥락

2026-11-17 사용자 요청:

- 커피 메뉴를 아메리카노, 카페라떼, 바닐라라떼, 헤이즐넛라떼, 카라멜마키아또, 카페모카, 카푸치노, 콜드브루, 콜드브루라떼로 바꾼다 (연유라떼 제외).
- 음료에서 딸기에이드를 빼고 딸기라떼 옆에 초콜릿라떼·말차라떼를 넣는다. 스무디에 밀크쉐이크를 넣는다.
- 포스기의 음료·스무디·디저트 탭과 레시피북에서 HOT/ICE 선택을 없앤다. 주문 표기는 `[HOT] 아메리카노`, 온도가 고정된 메뉴는 온도를 붙이지 않는다.
- 손 인벤토리를 4칸으로 늘린다 (기존 2칸).
- 재료 작업 창은 공용 그림이 아니라 딸기청은 딸기청 병처럼 재료마다 전용 그림을 쓴다.

판정은 재료 **종류 조합**으로 메뉴를 알아보므로(ADR-0014), 카푸치노는 카페라떼와 다른 재료가 필요하고, 콜드브루·말차·밀크쉐이크도 새 재료가 필요했다. 사용자가 질문에 답해 정한 것:

- 음료 온도: 차(캐모마일·얼그레이·유자차·자몽차)는 HOT 고정, 라떼·에이드는 ICE 고정
- 카푸치노: 새 재료 **시나몬 파우더** (샷 + 우유 150g + 시나몬)
- 밀크쉐이크: 새 재료 **바닐라 아이스크림** (믹서기)
- 연유: 쓰는 메뉴가 없어도 재료는 그대로 둔다

## 결정

- 새 재료 4종: `cold_brew`(콜드브루 원액, 붓기), `matcha`(말차 파우더, 숟가락), `cinnamon`(시나몬 파우더, 숟가락), `vanilla_ice_cream`(바닐라 아이스크림, 쉐이크 제조실 통). 콜드브루·말차·시나몬은 오픈 준비의 **커피** 탭, 바닐라 아이스크림은 **스무디** 탭에 둔다 (새 탭 그림을 만들지 않기 위해).
- 콜드브루·콜드브루라떼는 ICE 고정. 커피 탭만 HOT/ICE 선택이 남는다.
- 기존 `GameBalance.asset` 은 `EnsureCatalog` 가 코드의 메뉴 구성에 맞춘다: 메뉴 순서·온도는 코드 기준, 기존 가격·레시피 정량·아이콘·재고는 보존, 없어진 메뉴·온도의 레시피는 삭제, 새 메뉴·레시피·재료·시작 재고는 추가. 메뉴 id 는 바꾸지 않는다 (`caramel_macchiato` 는 표시 이름만 '카라멜마키아또').
- 손 칸은 `HandInventory.SlotCount = 4`, 빈 칸은 왼쪽부터 채운다. 왼손·오른손 구분은 없앤다.
- 재료 작업 창은 `IngredientToolArt` 표로 재료 id → 전용 그림을 찾고, 없으면 도구 공용 그림을 쓴다. 전용 그림은 공용 그림과 같은 캔버스·기하로 그려 잡는 영역·줄기 위치를 공유한다. 펌프 방울과 숟가락 낙하는 중립색 그림에 재료 색을 곱한다.
- 숟가락형 도구(청·말차·시나몬)는 한 번 끌어 넣을 때 10g (시럽 1회 투입량과 같음).
- 맨 위 팝업의 X 버튼은 HUD 캔버스보다 위(정렬 순서 50)로 올려, 주문 내역·레시피 버튼에 가려 안 눌리던 문제를 막는다.

## 검토한 대안

- 카푸치노를 우유 양만 다르게: 같은 재료 조합이면 판정이 메뉴를 구분하지 못해 판정 방식까지 바꿔야 함. 사용자가 시나몬을 골랐다.
- 우유 거품 단계 추가: 새 기기·조작이 필요해 작업량이 가장 큼.
- 음료를 온도별 메뉴 두 개로 나누기: 사용자가 온도 고정을 골랐다.
- 연유 재료 제거: 사용자가 그대로 두기로 했다.
- 새 재료용 오픈 준비 탭 추가: 탭 그림·배치 변경이 커서 기존 탭에 넣었다.
- HUD 버튼을 팝업이 열려 있을 때 숨기기: 기기 창에서 레시피를 볼 수 없게 되어 채택하지 않음.

## 결과

- 메뉴 33종 (음료 25 = 커피 9 + 음료 10 + 스무디·쉐이크 6, 베이커리 8). 손님 주문에도 새 메뉴가 나온다.
- 기존 저장 파일에는 새 재료 재고가 0 이다 (테스트용 `testFullStock` 이 켜져 있으면 가득 참).
- 연유는 어떤 레시피에도 쓰이지 않는다. 나중에 쓰는 메뉴가 없으면 오픈 준비 목록에서 빼는 것을 다시 검토한다.
- 새 재료를 추가할 때는 `DrinkRoomScreen.ExtraIds`(제조실 선반), 빌더의 `ToolArts`·`LiquidColors` 표도 같이 고친다.

# ADR-0035: 시럽·연유 펌프는 머리를 아래로 끌어 누른다

- 상태: 승인
- 날짜: 2026-11-17
- 관련 명세: SFR-046

## 맥락

ADR-0024에서 시럽·연유 작업 창은 펌프 병을 클릭 1회 할 때마다 1펌프가 들어가도록 했다. 사용자는 단순 클릭 대신 마우스 드래그로 넣도록 바꿔 달라고 했다 (2026-11-17). 청 숟가락·티백은 이미 끌기 방식이다 (ADR-0028).

## 결정

- 펌프 머리를 잡고 아래로 끌어내리면 머리가 눌리고, 끝까지(창 좌표 25px, 그림의 머리 이동 거리) 내리면 1펌프(`syrupPerClick`)가 들어간다.
- 절반 넘게 내리면 눌린 그림(`PumpBottlePressed`)으로 바뀌고, 1펌프가 들어가는 순간 방울을 보여 준다.
- 한 번 누를 때 1펌프만 들어간다. 마우스를 놓으면 머리가 올라오고, 다시 끌어내려야 다음 펌프가 들어간다.
- 잡는 영역은 펌프 머리 주변만이다. 병을 클릭해도 아무 일도 일어나지 않는다.

## 검토한 대안

- 펌프 병을 컵 위로 끌어다 놓기: 청 숟가락과 같은 방식이지만 실제 펌프 동작과 덜 비슷해서 사용자가 고르지 않았다.
- 끄는 거리만큼 머리 그림을 부드럽게 내리기: 머리만 따로 떼어 낸 그림이 필요하다. 지금은 기존 평소·눌림 그림 두 장을 바꿔 보여 준다.

## 결과

- 펌프 조작은 ADR-0024의 "클릭 1회 = 펌프 1회"를 대체한다. 다른 도구(청·티백·우유·탄산수)는 그대로다.
- 끝까지 누르는 거리는 `IngredientToolScreen.pumpPressDistance` 로 조정한다.

# ADR-0047: 달리기 기능을 없앤다

- 상태: 승인
- 날짜: 2026-11-19
- 관련 명세: SFR-016

## 맥락

명세서 SFR-016에 따라 Shift를 누르고 있으면 1.6배 빠르게 달리는 기능이 있었다. 사용자가 2026-11-19 "달리기 기능 없애줘"라고 요청했다.

## 결정

달리기를 없애고 플레이어는 걷기 속도로만 움직인다. Shift 입력, 달리기 속도 배율, 달리기 중 애니메이션 배속을 코드에서 지우고, 설정 화면의 조작 안내에서도 "달리기" 줄을 뺀다.

## 검토한 대안

- 설정에서 켜고 끄는 옵션으로 남기기: 사용자가 기능 자체를 없애 달라고 해서 채택하지 않았다.

## 결과

- 이동 속도는 `PlayerMovement.walkSpeed` 하나로 조절한다. 맵이 넓어서 답답하면 걷기 속도를 올린다.
- 명세서 SFR-016과 다르다 (GAME_DATA.md에 기록).

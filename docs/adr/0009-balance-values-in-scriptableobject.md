# ADR-0009: 밸런스 수치는 GameBalance ScriptableObject 하나에 모은다

- 상태: 승인 (구현 예정)
- 날짜: 2026-11-02
- 관련 명세: SFR-010, SFR-071, SFR-072 외 "추후 결정" 항목

## 맥락

명세에는 "추후 결정" 수치가 많다 (재료 단가·구매 단위, 일별 임대료, 시작 자금, 평판 초기값 ...).
이 값들은 오픈 준비, 정산, 새 게임 시작 등 여러 씬에서 함께 쓰이며, 플레이 테스트 중 자주 바뀐다.
씬별 컴포넌트의 `[SerializeField]` 로만 두면 같은 값이 여러 곳에 중복된다.

## 결정

- 여러 씬이 공유하는 수치는 `GameBalance` ScriptableObject 에셋 하나에 둔다.
- 런타임에서는 `Resources` 폴더의 에셋을 불러와 어디서든 같은 인스턴스를 쓴다.
- 한 화면에서만 쓰는 수치(애니메이션 시간 등)는 기존처럼 해당 컴포넌트의 `[SerializeField]` 로 둔다.

- 실제 수치와 상태(확정/임시/미정)는 [GAME_DATA.md](../GAME_DATA.md)에서 관리한다. 이 ADR은 "어디에 어떻게 두는가"만 정한다.

## 검토한 대안

- 상수(const)로 코드에 두기: 수치를 바꿀 때마다 코드 수정과 컴파일이 필요하다 (README 규칙 위반).
- JSON·CSV 파일: 수정하기는 쉽지만 아이콘 스프라이트를 참조할 수 없고 Inspector 검증이 없다.

## 결과

- 수치 조정은 `GameBalance.asset` 과 `GAME_DATA.md` 만 수정하면 된다. 수치 변경 PR은 이 두 파일만 바뀌므로 리뷰가 쉽다.
- `Resources` 사용은 이 에셋 하나로 제한한다.

# ADR-0022: 픽업대에서 선입선출을 어기면 감점한다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-056, SFR-067, SFR-068

## 맥락

사용자 요청 (2026-11-12): "주문을 선입선출로 처리 안 하면 감점되는 식?"

서빙 순서에 대한 규칙이 없어서 쉬운 주문만 골라 먼저 내보내도 손해가 없었다.

## 결정

서빙 버튼을 누를 때 그 주문보다 번호가 작은(먼저 들어온) 대기 주문이 남아 있으면 '주문 순서 어김' 1회로 기록하고 하루 점수에서 감점한다 (`DayResult.ordersSkipped`, `GameBalance.penaltyOrderSkipped`, 임시 30점). 득점 결과 화면의 감점 사항에 줄을 추가하고, 서빙할 때 안내 토스트를 띄운다.

픽업대 트레이 배치(가로 나열, ADR-0018)는 그대로 둔다. 세로 목록으로 바꿔 봤으나 트레이가 잘려 보여 사용자 요청으로 되돌렸다.

## 검토한 대안

- 기다리던 손님 만족도 감소, 또는 점수 감점과 함께 적용: 사용자가 점수 감점만 골랐다.

## 결과

- 순서대로 처리하는 것이 점수에 유리해져 주문 관리가 게임 요소가 된다.
- 손님이 떠나 사라진 주문은 대기 주문이 아니므로 순서 판단에서 빠진다.
- 득점 결과 화면의 감점 줄이 5개가 되어 줄 간격을 52 → 42 로 줄였다.

# ADR-0023: 영업 HUD 에 재료 재고를 표시하지 않는다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-013, SFR-049

## 맥락

명세서 SFR-013 은 영업 중 HUD 에 "주요 재료 재고"를 상시 표시하라고 한다. 지금은 HUD 위쪽 가운데에 원두·우유 재고(`StockBar`)를 보여 주었다.
사용자 피드백 (2026-11-12): "인게임 화면에서 왜 원두랑 우유 양이 뜨는지 모르겠어. 안 떠도 됨."

## 결정

영업 HUD 에서 재료 재고 표시를 없앤다 (`CafeHud` 의 재고 필드, `CafeUiBuilder` 의 StockBar, `GameBalance.lowStockWarning`). 명세서 SFR-013 의 "주요 재료 재고" 항목을 사용자 요청으로 뺀다.

## 검토한 대안

- 원두·우유 대신 다른 재료를 표시: 사용자가 표시 자체가 필요 없다고 했다.

## 결과

- HUD 가 단순해진다.
- 재고는 오픈 준비 화면(재고가 적으면 빨간색)과 기기 화면의 재료 칸(SFR-049 남은 양)에서 확인한다. 영업 중 재료가 떨어지면 '재료가 부족합니다' 토스트로 안다.
- `Art/UI/CafeHud/StockBar.png` 는 더 이상 쓰지 않는다.

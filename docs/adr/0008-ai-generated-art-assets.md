# ADR-0008: UI·아트 에셋은 AI 이미지 생성으로 만들고 생성 기록을 남긴다

- 상태: 승인
- 날짜: 2026-11-02
- 관련 명세: SFR-013

## 맥락

팀에 전담 아트 담당이 없고, 명세는 도트 그래픽과 통일된 UI를 요구한다(SFR-013).
화면마다 다른 사람이나 다른 프롬프트로 만들면 스타일이 어긋난다.

## 결정

- UI 디자인과 아트 에셋은 Codex(이미지 생성 도구)로 만든다. 코드 작업과 에셋 작업을 나눠 진행한다.
- 공통 스타일: 아늑한 한국풍 도트 카페, 또렷한 계단식 픽셀 외곽선, 호두나무·허니 골드·크림 팔레트, 투명 배경, 가장자리 여백.
- 새 에셋은 기존 에셋을 스타일 참조로 지정해 생성한다.
- 에셋 폴더마다 `Generation.md` 에 사용 도구, 스타일 참조 파일, 파일별 프롬프트를 남긴다.
- 임포트 설정: Sprite, Filter Mode Point, Mip Map 끔, Alpha Is Transparency 켬.

## 검토한 대안

- 무료 에셋팩 사용: 카페 기기(그라인더, 탬핑 스테이션 등) 전용 그림이 부족하고 스타일 통일이 어렵다.
- 직접 도트 작업: 일정상 화면 수(기기 화면 10개 이상)를 감당하기 어렵다.

## 결과

- 글자가 들어간 이미지는 철자를 직접 확인한다. 금액·수량처럼 바뀌는 글자는 이미지에 넣지 않고 TextMeshPro로 표시한다.
- 생성 기록이 있으므로 같은 스타일로 에셋을 다시 만들거나 추가할 수 있다.

# ADR-0027: 음료 판정 결과는 완성품 그림과 완성도 도장으로 보여 준다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-051, SFR-055

## 맥락

음료 제조실·쉐이크 제조실에서 완성을 누르면 '판정 결과' 제목이 있는 카운터 그림 창에 메뉴 이름과 등급 글자(완벽·좋음·나쁨·실패한 음료)를 보여 주었다.
사용자 요청 (2026-11-12): "'판정결과' 없애고, 그냥 완성품 에셋에다가, 완성도 에셋들 캐주얼하게 그려서 그렇게 뜨도록".

## 결정

- 결과 창 패널을 없애고, 제조실 창 가운데에 **완성품 음료 그림**이 떠오르고 옆에 **완성도 도장**(완벽! · 좋아요 · 아쉬워요 · 실패)이 찍힌다. 아래에 메뉴 이름 글자. 화면은 살짝 어둡게.
- 완성품 그림은 비슷한 메뉴끼리 묶어 그린다 (사용자 선택 "메뉴 종류별"): 아메리카노, 라떼류(카페·바닐라·헤이즐넛·연유), 카라멜, 모카, 딸기라떼, 에이드 4색, 청차 2종, 티, 스무디 4종, 쿠키 쉐이크 — HOT/ICE 별. 그림 위치는 `Art/UI/DrinkResult`.
- 레시피에 없는 조합(실패)은 엉망인 음료 그림(HOT/ICE)과 '실패' 도장, 이름은 '알 수 없는 음료'.

## 검토한 대안

- 메뉴마다 1장(약 35장): 그림이 너무 많아 묶었다.
- 별점, 리본 배지: 사용자가 도장을 골랐다.
- 작은 카드 위에 표시: 사용자가 배경 없이 띄우는 쪽을 골랐다.

## 결과

- 메뉴를 추가하면 `DrinkResult` 그림과 빌더의 메뉴→그림 표에 한 줄을 더해야 한다. 표에 없으면 실패 그림이 나오지 않도록 주의 (메뉴는 맞지만 그림이 없으면 실패 그림이 대신 나온다).
- 등급 이름 '나쁨'은 도장에서 '아쉬워요'로 보인다.

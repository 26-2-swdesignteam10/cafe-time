# ADR-0052: 퇴식구의 잔·접시는 손으로 운반해 설거지실 설거지 대기 바구니에 넣는다

- 상태: 승인
- 날짜: 2026-11-24
- 관련 명세: SFR-021, SFR-059~065

## 맥락

지금까지 퇴식구 화면에는 쓰레기통과 설거지통이 있었다. 잔·접시를 설거지통에 넣으면 곧바로 설거지실 대기 목록으로 옮겨졌다. 사용자가 2026-11-24에 이 방식을 바꿔 달라고 요청했다. "퇴식구에서 '설거지통' 항목을 없애고, 직접 인벤토리로 운반하는 방식으로 바꾸어 줘. 더러워진 식기는 설거지 창에서 '설거지 대기' 통에 드래그해서 보관하는 식으로."

## 결정

- 퇴식구 화면에서 설거지통 칸(대야, 쌓인 잔·접시 그림, 라벨)을 없앤다. 쓰레기(빨대, 냅킨, 티백)는 전처럼 쓰레기통으로 끌어 버린다.
- 쟁반 위 잔·접시는 손 칸으로 끌어 놓거나 눌러서 가져온다. 누르면 손 칸으로 날아간다. 손에는 새 물건 `DirtyDish`(더러운 잔·접시)로 들린다. 손이 가득 차면 '인벤토리가 가득 찼습니다.'를 띄우고 쟁반에 남긴다.
- 설거지실 화면의 설거지 대기 바구니(`WaitingCrate`)가 놓는 자리가 된다. 손 칸의 더러운 잔·접시를 끌어 놓거나, 손 칸을 고른 뒤 바구니를 누르면 대기 목록에 들어간다. 그 뒤 싱크대·건조대 흐름은 그대로다.
- 더러운 잔·접시는 손 칸 우클릭 '버리기' 메뉴로 없앨 수 없다. 메뉴가 열리지 않는다.
- 손에 든 커피잔을 '버리기' 하면 설거지 대기로 바로 가는 규칙(SFR-021)은 이번 요청 범위가 아니라서 그대로 둔다.

## 검토한 대안

- 손에 든 더러운 잔·접시도 '버리기'로 대기 목록에 보내기: 직접 운반한다는 요청의 취지를 우회할 수 있어 채택하지 않았다.
- 손 칸 안내 문구("설거지 대기 바구니에 넣어 주세요")를 새로 띄우기: 안내 문구가 글자 이미지라 새 그림이 필요하다. 메뉴를 열지 않는 것만으로 충분하다고 보고 보류했다.

## 결과

- 설거지까지 플레이어가 직접 들고 옮겨야 해서 동선과 손 칸 관리가 게임 요소가 된다. 손 칸 4칸 중 일부를 더러운 식기가 차지할 수 있다.
- 퇴식구 안내 문구 이미지(`Art/UI/TrayReturn/Hint.png`)를 새 방식에 맞게 바꾼다.
- 퇴식구의 `DishBin.png`, `DishBinFront.png`, `LabelDishBin.png`는 더 이상 쓰지 않는다.
- 씬 반영은 `CafeTime/Build Cafe Scene`으로 다시 빌드해야 한다.

# ADR-0045: 진동벨 번호를 1~30 중 무작위로 준다

- 상태: 승인
- 날짜: 2026-11-19
- 관련 명세: SFR-027, SFR-056

## 맥락

주문 번호(진동벨 번호, ADR-0040)는 하루 동안 1부터 차례로 올라갔다. 사용자가 2026-11-19 "진동벨 번호는 1~30번까지 랜덤 배치로" 요청했다.

## 결정

- 주문을 받을 때 1~30 중 **지금 대기 중인 주문과 겹치지 않는** 번호를 무작위로 준다. 끝난 주문의 번호는 다시 나올 수 있다 (사용자 선택). 최댓값은 `OrderBoard.maxBellNumber`.
- 번호가 더 이상 순서를 뜻하지 않으므로, 주문 순서 어김 감점(ADR-0022)은 번호 크기가 아니라 **주문이 들어온 순서**(주문 목록 순서)로 판단한다.

## 검토한 대안

- 하루 동안 번호 중복 없이 쓰다가 30번을 다 쓰면 재사용: 사용자가 고르지 않았다.

## 결과

- 번호만 보고 먼저 온 주문을 알 수 없어, 주문 내역·픽업대의 목록 순서(들어온 순서)를 보고 호출해야 한다.
- 대기 주문이 30개를 넘으면 31번 이상을 준다 (실제로는 일어나지 않음).

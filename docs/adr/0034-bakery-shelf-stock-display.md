# ADR-0034: 빵 진열대는 재고만큼 작은 빵을 칸마다 늘어놓고 홀 세로를 채운다

- 상태: 승인
- 날짜: 2026-11-17
- 관련 명세: SFR-056

## 맥락

ADR-0032에서 손님이 아래쪽 큰 빵 진열대에서 직접 빵을 집기로 했다. 그런데 진열대 그림(`BreadShelf.png`) 한 장에 칸마다 큰 빵이 1~2개씩 그려져 있어, 빵이 크고 듬성듬성해 보였다. 재고가 줄거나 품절돼도 진열대 모습은 그대로였다. 또 진열대가 홀 아래쪽으로 치우쳐 보였다.

사용자는 빵을 훨씬 작게 만들어 칸마다 여러 개를 예쁘게 늘어놓고, 진열대가 홀 가운데에 있는 느낌이 나도록 위로 옮기거나 세로로 늘려 달라고 했다. 인터뷰에서 아래 방식을 골랐다.

## 결정

- `BreadShelf.png` 는 빵이 없는 빈 진열대(2열×4행 8칸, 336×640px = 2.625×5칸)로 다시 그린다.
- 빵은 종류별로 작은 그림(48×40px, `Art/Sprites/Cafe/Bakery/`)을 따로 두고, `BakeryShelfView` 가 칸마다 **남은 재고만큼**(칸당 최대 6개, 앞줄 3개부터) 늘어놓는다. 품절이면 칸이 빈다.
- 진열대 2개는 같은 8종을 같은 칸 순서로 담고, 재고를 번갈아 나눠 보여 준다.
- 칸 순서는 기존 그림과 같다: 딸기 케이크·크루아상 / 베이글·와플 / 샌드위치·크로크무슈 / 쿠키·허니브레드.
- 진열대는 세로로 늘려 아래쪽 손님 통로(y 1.25) 바로 위(y 1.55)부터 포스기 앞 줄(y 7.25) 아래(y 6.55)까지 홀 가운데를 채운다. 충돌 영역은 1.9×5칸, 손님 픽업 위치(6, 4)는 그대로다.

## 검토한 대안

- 작은 빵이 가득 담긴 진열대 그림 한 장으로 다시 그리기: 빠르지만 재고와 상관없이 늘 가득 차 보여서 채택하지 않았다.
- 크기는 두고 위로 올리기: 아래쪽 바닥이 비어 보여서 세로로 늘리는 쪽을 골랐다.
- 왼쪽·오른쪽 진열대에 4종씩 나눠 담기: 칸이 커지지만, 지금처럼 8종을 한 칸씩 담는 배치를 유지하기로 했다.

## 결과

- 진열대만 봐도 무엇이 얼마나 남았는지 알 수 있다.
- 빵 종류를 추가하면 진열대 그림의 칸 수, `CafeSceneBuilder` 의 칸 좌표·품목 표, 작은 빵 그림을 함께 늘려야 한다.
- 칸 좌표는 `Art/Sprites/Cafe/Generation.md` 의 측정값을 따른다. 진열대 그림을 다시 그리면 좌표도 다시 잰다.

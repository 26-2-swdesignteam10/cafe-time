# ADR-0016: 카페 맵을 주방 축소 배치와 모던 스타일로 바꾼다

- 상태: 제안
- 날짜: 2026-11-05
- 관련 명세: SFR-012, 024, 025

## 맥락

사용자가 기존 맵이 마음에 들지 않고 특히 플레이어 주방이 너무 넓다고 했다 (가로 24칸). 구역 배치는 레퍼런스 이미지(왼쪽 위 주방, 왼쪽 아래 입구와 진열대, 오른쪽 좌석)를 따르되, 디자인은 레퍼런스를 따르지 않고 "깔끔하고 모던한 카페 배경"으로 하기로 했다.

## 결정

사용자가 평면도와 스타일 방향을 확인했다. 아래 "미확정" 항목이 남아 있어 전체 상태는 `제안` 으로 둔다.

**확정된 배치 (26x15칸)**

- 주방 이동 공간 9x3칸. 주방 출입구는 앞쪽 카운터 맨 왼쪽(x1)
- 앞쪽 카운터: 포스기(x4~5.25), 픽업대(x5.25~10, 4.75칸으로 넓힘)
- 뒤쪽 벽 오른쪽부터: 에스프레소 머신, 정수기, 음료대, 잔 선반, 제빙기
- 출입문은 왼쪽 아래(x1~2). 원형 진열대는 없애고 빵 진열대 2개를 세로로 늘린다
- 오븐과 냉장고는 넣지 않는다

**확정된 스타일 방향**

- 도트 그래픽은 유지하고 맵 그림만 밝은 무채색과 우드 톤의 미니멀 스타일로 바꾼다. UI는 지금 스타일을 유지한다.

**손님 동선**

- 문 → 입구 세로 통로(x2.5) → 포스기 앞 줄(y7.25) → 진열대 오른쪽(x9.5) → 화분 사이(y3.7) → 좌석 세로 통로(x11.1) → 테이블 줄의 가로 통로. ADR-0013의 "가운데 세로 통로" 동선을 대신한다.
- 줄은 포스기에서 왼쪽으로 이어지다 입구 쪽으로 꺾인다. 입구까지 차면(5일행) 더 들어오지 않고 감점도 없다.

**미확정 (인게임 확인을 위해 임시로 정함)**

- 행주·디저트 진열장은 빈 카운터(x2~4), 설거지실·쉐이크대는 뒤쪽 벽 빈자리(x1~3.75), 퇴식구는 홀 왼쪽 벽. 기능을 유지하려고 넣은 자리다.
- 빵 진열대, 화분, 창가 바, 스툴, 부스는 충돌만 있는 가구다. 창가 바와 부스에는 아직 앉지 않는다.
- 테이블은 레퍼런스의 2인용 원형이 아니라 기존 4인용 그림을 쓴다. 일행이 최대 4명이기 때문이다. 좌석 구성은 좌석 그림을 만들 때 정한다.
- 맵 그림 전체를 Codex가 새 스타일로 그렸고, 사용자의 최종 확인이 남아 있다.
- 사용자가 벽이 이상하고 기기가 작다고 해서 벽을 그레이지 면 + 어두운 윗면 구조로 바꾸고 창문을 넣었으며, 카메라를 세로 10칸에서 8칸으로 확대했다. 이동 속도는 초당 4.5칸으로 올렸다 (`docs/GAME_DATA.md`).

## 검토한 대안

- 기기를 없앤 채로 구현: 행주, 디저트 진열장, 설거지실, 쉐이크대를 빼면 청소, 디저트, 설거지, 쉐이크 기능을 쓸 수 없어 임시 자리에 둔다.
- 새 그림을 모두 만든 뒤 구현: 사용자가 먼저 게임 안에서 배치를 보기로 했다.
- 퇴식구를 주방 카운터에 둠: 동선은 짧지만 사용자가 레퍼런스 평면도를 승인한 뒤 위치를 바꾸지 않아 일단 홀에 둔다.

## 결과

- 주방이 좁아져 기기 사이 이동이 짧아진다.
- 플레이어는 쟁반, 테이블 청소를 위해 주방 밖으로 나가야 한다. 주문 줄이 주방 출입구 근처를 지나므로 플레이 테스트에서 막힘 여부를 확인한다.
- 미확정 항목이 정해지면 이 ADR의 상태를 `승인` 으로 바꾸거나 새 ADR로 정리한다.

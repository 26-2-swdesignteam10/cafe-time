# ADR-0010: 재료 재고는 기본 단위(g·개·회)로 저장하고 구매 단위는 변환해서 쓴다

- 상태: 승인 (구현 예정)
- 날짜: 2026-11-02
- 관련 명세: SFR-010, SFR-031, SFR-046, SFR-047, SFR-049, SFR-053, SFR-056

## 맥락

재료를 사는 단위와 쓰는 단위가 다르다.

- 오픈 준비(SFR-010): 원두 1봉, 우유 1팩처럼 **구매 단위**로 산다.
- 그라인더(SFR-031): 분쇄 1회당 원두 차감
- 음료 제조(SFR-046, 047): 시럽·우유는 g 단위로 투입, 남은 양은 %로 표시(SFR-049)
- 티백·디저트: 개수 단위

## 결정

- 재고는 재료마다 하나의 **기본 단위** 정수로 저장한다.

  | 재료 | 기본 단위 | 구매 단위 예 |
  |---|---|---|
  | 원두 | 회(분쇄 1회분) | 1봉 = 20회 |
  | 우유·탄산수·시럽·청·연유·스무디 원액 | g | 1병 = 1,000g |
  | 티백 | 개 | 1박스 = 10개 |
  | 디저트 | 개 | 1개 = 1개 |

- 재료 정의(`GameBalance`)에 `id`, 이름, 카테고리, 구매 단위 이름, 구매 단위당 기본 단위 양, 단가, 아이콘을 둔다.
- 저장 데이터(`SaveData`)에는 `id` 와 기본 단위 수량 목록만 저장한다.
- 남은 양 %(SFR-049)는 "구매 단위 1개 대비 남은 양"으로 계산해 표시한다.
- 남은 재고는 모두 다음 날로 이월한다(SFR-010).

## 검토한 대안

- 구매 단위 개수(병 수)로 저장: 시럽 1회 투입처럼 1병보다 작은 양을 표현하려면 소수가 필요하고 오차가 쌓인다.
- 재료마다 별도 필드: 재료를 추가·삭제할 때마다 저장 형식이 바뀐다.

## 결과

- 재료를 쓰는 모든 기능은 재료 `id` 와 기본 단위 수량으로 재고를 차감한다.
- 재료 `id` 는 저장 파일에 남으므로, 한번 정한 `id` 는 바꾸지 않는다.

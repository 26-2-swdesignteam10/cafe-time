# ADR-0019: 레시피북 온도 선택, 빈 스쿱 자동 반납, 기기 창 제목·안내 문구 제거

- 상태: 승인
- 날짜: 2026-11-11
- 관련 명세: SFR-037~040, SFR-044~055, SFR-051, SFR-056~057

## 맥락

플레이 테스트 후 사용자 피드백(2026-11-11):

- 레시피북이 HOT·ICE 카드 두 장을 나란히 보여 줘서 공간을 잘 못 쓴다 (ADR-0017 의 "오른쪽에 HOT·ICE 레시피 카드").
- 얼음을 컵에 부은 뒤 빈 스쿱을 제빙기에 직접 반납하러 가야 해서 번거롭다.
- 기기 창마다 위쪽 제목과 아래 안내 문구가 있어 화면이 복잡하다. 음료 제조실의 저울 위 컵은 작은 아이콘이라 실제 컵처럼 보이지 않는다.

## 결정

1. **레시피북**: 오른쪽에 큰 레시피 카드 1장과 HOT/ICE 선택 버튼을 둔다. 메뉴를 바꿔도 고른 온도를 유지하고, 그 온도의 레시피가 없는 메뉴(HOT 전용·ICE 전용)는 없는 쪽 버튼을 비활성화하고 있는 쪽을 보여 준다. ADR-0017 의 레시피북 카드 배치만 바꾼다.
2. **빈 스쿱 자동 반납**: 얼음 스쿱으로 음료 제조실 저울 위 잔(또는 쉐이크 제조실 믹서기)에 얼음을 부으면 빈 스쿱은 손에서 빠져 제빙기 스쿱 자리로 바로 돌아간다.
3. **기기 창 제목·안내 문구 제거**: 커피잔 선반, 제빙기, 정수기, 음료 제조실, 쉐이크 제조실, 설거지실, 디저트 진열장의 제목을 패널 그림에서 지운다. 제빙기, 정수기, 음료 제조실, 쉐이크 제조실, 설거지실, 픽업대의 안내 문구를 빼고, 픽업대와 퇴식구의 제목은 남긴다.
4. **음료 제조실 큰 컵**: 저울 위 잔은 손 칸 아이콘 대신 큰 컵 일러스트(HOT·ICE × 빈 잔·물·만드는 중)로 보여 준다. 비우기·완성 버튼은 빈 버튼 그림 위에 글자 그림을 가운데 정렬로 얹는다.

## 검토한 대안

- 레시피북 HOT/ICE 탭에서 없는 온도 버튼을 숨기기: 버튼 위치가 메뉴마다 바뀌어 사용자가 비활성화를 골랐다.
- 스쿱을 손에 남겨 두고 버리기 메뉴로 반납 (기존): 사용자가 번거롭다고 함.

## 결과

- 레시피 한 장을 크게 보여 줘서 글자와 아이콘이 커진다.
- 스쿱은 손 칸을 덜 차지하지만, 얼음을 두 번 넣으려면 제빙기로 다시 가야 한다.
- 안내 문구가 빠지므로 처음 하는 사람은 조작법을 게임 방법(HowTo)이나 토스트로 알아야 한다.
- 지운 안내 문구 그림(`Hint.png`, `PourHint.png`, `PickupHint.png`)과 레시피 배지(`BadgeHot.png`, `BadgeIce.png`)는 더 이상 쓰지 않는다.

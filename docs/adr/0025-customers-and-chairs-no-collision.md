# ADR-0025: 손님과 의자는 플레이어와 충돌하지 않는다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-017, SFR-024

## 맥락

2026-11-12 버그 목록에서 두 가지가 보고되었다.

1. 중간중간 막히는 곳이 있다 (홀, 퇴식구 앞)
2. 손님이 주인공을 밀고 올라간다

원인은 다음과 같았다.

- 홀: 테이블 양옆 의자에 0.5칸 너비의 충돌 영역이 있어, 옆 테이블 의자와의 틈이 0.3칸뿐이었다. 플레이어 발 충돌 영역은 0.6칸이라 테이블 사이를 세로로 지나갈 수 없었고, 화분 칸막이와 첫 번째 의자 사이(0.45칸)도 막혀 있었다.
- 퇴식구 앞: 두 번째로 줄 선 일행이 입구 세로 통로(x2.5, 퇴식구 바로 앞)에 선다. 이 통로는 퇴식구와 빵 진열대 사이 약 1.1칸이라 손님 한 명이 서면 플레이어가 지나갈 수 없었다.
- 밀림: 손님은 Kinematic Rigidbody2D인데 `transform.position` 으로 위치를 옮긴다. 플레이어 위로 겹쳐 들어오면 물리 엔진이 Dynamic인 플레이어를 밀어낸다.

## 결정

사용자가 "손님 통과 가능" 안을 선택했다.

- 손님에게 충돌 영역(Rigidbody2D, Collider2D)을 붙이지 않는다. 플레이어와 손님은 서로 통과한다.
- 테이블 의자에도 충돌 영역을 두지 않는다. 테이블, 화분, 진열대 등 나머지 가구와 벽·기기는 그대로 막는다.
- 플레이어 발 충돌 영역의 모서리를 둥글게 한다 (`edgeRadius` 0.05, 바깥 크기는 0.6x0.3 그대로). 이어 붙은 벽 타일과 화분 사이 이음새에 걸리는 것을 줄인다.

SFR-017(충돌)은 "벽·기기·가구에 막힌다"로 해석한다.

## 검토한 대안

- 손님은 막되 양보: 서 있는 손님은 계속 막고, 걷는 손님은 플레이어가 앞에 있으면 멈춰 기다린다. 밀림은 없어지지만 줄 위치를 퇴식구 앞에서 옮기고 의자 충돌을 줄이는 등 손님 동선(ADR-0016)을 바꿔야 해서 채택하지 않았다.
- 테이블 간격을 넓힘: 홀 가로 공간(화분 칸막이 x11 ~ 부스 x22.3)에 4인 테이블 3개를 두면 의자 충돌을 줄여도 틈이 플레이어 발 너비와 비슷해 여전히 빠듯하다.

## 결과

- 홀 테이블 사이와 퇴식구 앞을 자유롭게 지나갈 수 있고, 손님이 플레이어를 밀지 않는다.
- 플레이어가 손님·의자 그림과 겹쳐 보일 수 있다. 정렬은 발밑 기준(Y축)이라 앞뒤 순서는 자연스럽게 바뀐다.
- 이후 손님 NPC나 좌석 가구를 추가할 때도 플레이어 충돌 영역을 붙이지 않는다.

# ADR-0039: 영업 HUD에서 임대료를 빼고 DAY 그림·원 표기·평판 숫자를 쓴다

- 상태: 승인
- 날짜: 2026-11-17
- 관련 명세: SFR-013, SFR-043, SFR-072

## 맥락

2026-11-17 사용자 요청: "DAY 는 에셋으로 1~15까지 구현", "보유금 텍스트 없애고 코인 아이콘 좀 더 키우고 그 옆에 소지금", "임대료 파트 없애", "평판 별끼리의 거리 조금 더 가깝게 하고 옆에 1~5 까지 소수점 첫째 자리까지 표시". 명세 SFR-013 은 영업 HUD 에 당일 임대료를 표시하도록 되어 있어 명세와 달라지는 결정이다. 금액 형식은 사용자가 `150,000원` 을 골랐다 (Jua 폰트에서 ₩ 가 백슬래시처럼 보임). DAY 그림은 지금 HUD 나무판에 맞춘 도트로 골랐다.

같은 요청에서 정수기 물 받기가 너무 빠르니 3초 늘리고, 컵에 물이 실시간으로 차는 게 보이게 해 달라고 했다.

## 결정

- 영업 HUD 1줄: DAY 그림(`Art/UI/CafeHud/Day1~15.png`) + 시각. 2줄 대신 1줄 오른쪽에 코인 아이콘 + `150,000원`.
- 영업 HUD 2줄: 평판 라벨 + 별 5개(간격 34 → 29) + 평판 숫자 소수 첫째 자리(`3.4`).
- 영업 HUD 에서 당일 임대료를 표시하지 않는다. 임대료는 정산 화면에서만 보인다.
- 주문 내역·레시피 버튼을 230×124 로 키우고 큰 아이콘 + 글자 그림으로 바꾼다.
- 정수기는 6초 동안 물을 조금씩 부어 컵 속 물이 차오르는 것이 보이게 한다 (합계 200g 그대로).

## 검토한 대안

- 금액을 `₩150,000` 으로 유지: 사용자가 `원` 표기를 골랐다.
- DAY 를 모던 배지로: 사용자가 기존 도트 HUD 에 맞추는 쪽을 골랐다.
- 임대료를 작게라도 남기기: 사용자가 없애 달라고 했다.

## 결과

- 명세 SFR-013 의 "당일 임대료 표시"와 다르다. 팀원에게 공유가 필요하다.
- DAY 가 15를 넘는 일은 없지만, 그림이 없으면 글자 `DAY n` 으로 대신 표시한다.
- 정수기 물을 받는 동안 매 프레임 컵 상태가 바뀌므로 정수기 화면이 매 프레임 다시 그려진다.

# ADR-0046: HOT 우유 메뉴는 스팀 피처로 데운 우유를 쓴다

- 상태: 승인
- 날짜: 2026-11-19
- 관련 명세: SFR-044~051

## 맥락

HOT 라떼도 냉장 우유를 그대로 부어 만들었다. 사용자가 2026-11-19 "뜨거운 우유가 필요한데, 음료제조실에서 우유스티밍 하는 모달창을 새로 구현해줘"라고 요청했고, 인터뷰에서 아래를 골랐다.

- 흐름: 피처에 우유 붓기 → 스팀 → 컵에 붓기
- 온도: 적정 구간을 벗어나면 등급 한 단계 하락
- 적용: HOT 우유 메뉴 전부, 차가운 우유를 넣으면 실패

## 결정

- 음료 제조실에 "스팀 피처" 버튼을 두고, 누르면 우유 스티밍 창(`SteamScreen`)이 겹쳐 열린다.
  - 우유팩을 꾹 누르면 피처에 우유가 부어진다 (재고는 우유 `milk` 에서 차감, 피처 용량 제한).
  - 스팀 완드를 꾹 누르면 피처 우유 온도가 오른다. 온도계에 적정 구간(60~70℃)이 보인다.
  - 피처를 꾹 누르면 저울 위 잔에 스팀 우유(`RecipeKeys.SteamedMilk` = `milk_steamed`)가 부어진다.
  - 비우기 버튼으로 피처를 비우면 버린 재료 감점(SFR-050과 같음).
  - 피처 상태는 `DrinkStation.Pitcher` 에 있어 창을 닫아도 유지된다. 잔이 없어도 붓기·스팀은 할 수 있다.
- HOT 카페라떼·바닐라라떼·카라멜마키아또·헤이즐넛라떼·카페모카·카푸치노·콜드브루라떼 레시피의 우유는 `milk_steamed` 이다. 차가운 우유를 넣으면 재료 구성이 달라 '실패한 음료'.
- 적정 구간 밖의 스팀 우유를 부은 잔은 판정 때 등급이 한 단계 내려간다 (완벽→좋음, 좋음→나쁨). 수치는 `GameBalance` (임시값, docs/GAME_DATA.md).

## 검토한 대안

- 기존 우유 붓기 창에 스팀 단계 추가: 사용자가 별도 창 흐름을 골랐다.
- 스팀 버튼만 누르면 정량 우유가 바로 들어가는 간단한 방식: 사용자가 고르지 않았다.
- 너무 뜨거우면 '탄 우유'로 실패: 사용자가 등급 하락을 골랐다.

## 결과

- HOT 우유 메뉴 제조 단계가 하나 늘어 난이도가 오른다.
- 스팀 우유는 구매 재료가 아니라 레시피 key 라서, 레시피북·내용물 색표·판정에서 따로 다룬다.
- 같은 잔에 적정·부적정 우유를 섞어 부으면 한 번이라도 부적정이면 하락한다.

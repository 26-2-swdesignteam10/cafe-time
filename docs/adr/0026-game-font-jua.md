# ADR-0026: 게임 폰트를 Jua로 변경

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: 없음 (아트 스타일)

## 맥락

게임 폰트는 도트 폰트 Galmuri11이었다 (ART_STYLE 4장). 사용자가 Galmuri11이 마음에 들지 않는다며 "도트형 말고 매끈한 폰트로 컨셉을 바꾸고 싶다"고 했다.
매끈한 한글 무료 폰트 후보(Pretendard, Jua, Do Hyeon, Gowun Dodum 등)를 미리보기로 비교했고, 사용자가 Jua를 골라 "Jua 체로 싹다 바꾸어 달라"고 했다.

고정 문구는 이미지에 그려 넣는 규칙이 있다 (ART_STYLE 4장). 그래서 TMP 폰트만 바꾸면 바뀌는 값(금액·수량·닉네임)만 바뀌고, 버튼·창 제목·라벨 이미지 속 글자는 Galmuri11로 남는다.

## 결정

- 게임의 모든 글자를 **Jua**(`Art/Fonts/Jua-Regular.ttf`, SIL OFL 1.1)로 쓴다.
- TMP 폰트 에셋은 `Art/Fonts/Jua SDF.asset` 이다. `CafeTime > Setup Fonts` 가 만들고 TMP 기본 폰트로도 지정한다.
- 이미 만든 프리팹·씬의 TMP 글자는 `CafeTime > Apply Game Font To All` 로 한 번에 바꾼다. 씬을 다시 빌드하지 않으므로 에디터에서 손본 내용은 유지된다.
- 고정 문구 이미지(버튼, 창 제목, 라벨, 안내문)의 글자도 Jua로 다시 조판한다. "고정 문구는 이미지로 넣는다"는 규칙은 그대로 둔다.
- 그림(패널, 기기, 아이콘, 맵)의 화풍은 바꾸지 않는다. 바뀌는 것은 글자뿐이다.

## 검토한 대안

- TMP 폰트만 바꾸기: 작업이 가장 적지만, 한 화면 안에 도트 글자 이미지와 매끈한 TMP 글자가 섞인다. 사용자가 "싹다"를 원해서 채택하지 않았다.
- Pretendard: 가독성은 가장 좋지만 카페 경영 게임의 귀여운 분위기와는 거리가 있다. 사용자가 Jua를 골랐다.
- 고정 문구를 이미지 대신 TMP로 표시하기: 글자를 다시 조판하는 일은 없어지지만 ART_STYLE 4장 규칙을 뒤집는 큰 변경이라 이번 범위에서 제외했다.

## 결과

- 화면의 글자가 한 가지 매끈한 폰트로 통일된다.
- 고정 문구가 들어간 PNG를 모두 다시 만들어야 한다. 다시 만든 PNG는 해당 폴더 `Generation.md` 에 기록한다.
- 도트(Point 필터) 폴더에 있는 글자 이미지는 반으로 줄여 표시할 때 가장자리가 거칠어 보일 수 있다. Play 테스트에서 확인하고, 필요하면 글자 라벨만 Bilinear로 바꾼다.
- Galmuri11 파일(`Galmuri11.ttf`, `Galmuri11 SDF.asset`, `Galmuri-OFL.txt`)은 참조가 모두 없어진 것을 확인한 뒤 Unity에서 지운다.

# ADR-0050: DAY 11 점심시간 러시는 정해진 시간 동안 손님이 몰려와 대부분 ICE 아메리카노를 주문하고 금방 떠난다

- 상태: 제안
- 날짜: 2026-11-25
- 관련 명세: SFR-009, SFR-024, SFR-025, SFR-057, SFR-066
- 관련 ADR: ADR-0020(DAY별 난이도 표), ADR-0042(단체 주문), ADR-0048(인플루언서)

## 맥락

명세서 SFR-009 의 DAY 11 은 "점심시간 러시 이벤트 - 특정 시간에 손님과 주문이 집중되어 주문 처리와 동선 관리 요구" 한 줄뿐이다. 시간대, 손님 수, 메뉴는 정해져 있지 않다.

2026-11-25 사용자가 러시 메뉴를 아이스 아메리카노로 정했다 ("메뉴는 아이스아메리카노로").

DAY 4·6 이벤트와 달리 선택지가 없고, 새 주문 방식도 필요 없다. 평소 손님 흐름(입장 → 줄 → 포스기 주문 → 자리 → 진동벨 → 퇴장)을 그대로 두고 그 시간대의 손님 수와 주문만 바꾸면 된다.

## 결정

1. **정해진 시간대(기본 11:30~13:30)에 입장 간격을 따로 쓴다.** `CustomerManager` 가 러시 중에는 DAY별 난이도 표(ADR-0020) 대신 러시 입장 간격(기본 6~10 실제 초)과 일행 인원 가중치(1~2명 위주)를 쓴다. 인플루언서 손님 수 배율(ADR-0048)은 그대로 곱한다.
2. **러시 손님은 러시 메뉴를 주문한다.** 손님 1명마다 `menuChance`(기본 100%) 확률로 러시 메뉴(기본 ICE 아메리카노)를 고르고, 아니면 평소처럼 무작위 음료를 고른다. 점심을 먹고 커피만 사러 온 손님이라 베이커리는 고르지 않는다. 주문은 평소처럼 포스기에서 대사를 보고 입력한다.
3. **자리가 나는 대로 바로 들어온다.** 러시 중에 만석이거나 줄이 가득 차 못 들어오면 다음 입장까지 기다리지 않고 짧은 간격(`CustomerManager.rushRetrySeconds`, 기본 1초)마다 다시 시도한다. 테이블 청소·퇴식구 쟁반 정리가 늦으면 그만큼 손님을 못 받는다 → "동선 관리" 부담.
4. **러시 손님은 음료를 받고 평소의 절반만 머문다**(`stayMultiplier`, 기본 0.5). 자리 회전이 빨라 쟁반 반납·청소가 몰린다.
5. **시작 때 대화창으로 알린다.** 시작 시각에 "직장인 손님" 이 선택지 없는 대화창(`EventDialog`, ADR-0048 의 대사 모드)으로 점심 러시와 메뉴를 알린다. 대화 중에는 게임 시간이 멈춘다. 다른 이벤트 대화 중이면 끝난 뒤 시작한다. 씬을 다시 빌드하지 않도록 대화창은 씬에서 찾아 쓰고, 없으면 안내 없이 러시만 시작한다.
6. 러시 손님의 만족도·팁·이탈·환불·선입선출은 일반 손님과 같다. 선택 결과가 없어 `SaveData.choices` 에 남기지 않는다.
7. 설정(DAY, 시작·끝 시각, 입장 간격, 인원 가중치, 메뉴·온도, 메뉴 확률, 머무는 시간 배율)은 `GameBalance.lunchRushes` 의 `LunchRushEvent` 목록에 둔다.

## 검토한 대안

- 러시 손님을 포장(테이크아웃) 손님으로 받아 자리에 앉지 않고 픽업대 앞에서 기다리게 함: 좌석 수에 막히지 않아 더 많이 몰려오지만 손님 동선·대기 상태를 새로 만들어야 해서 고르지 않았다. 대신 머무는 시간을 줄이고 자리가 나는 즉시 들어오게 했다.
- 러시를 별도 매니저 컴포넌트로 분리: 단체 주문·인플루언서처럼 씬 빌더 수정과 Cafe 씬 재빌드가 필요해, 입장 흐름을 가진 `CustomerManager` 안에 두었다.
- DAY 11 전체 난이도만 올림: "특정 시간에 집중" 이라는 명세와 맞지 않는다.

## 결과

- DAY 11 영업 중 약 1분(게임 2시간) 동안 손님이 평소의 3~4배로 몰리고 같은 메뉴가 연달아 들어와, 아이스 아메리카노를 미리 여러 잔 만들어 두는 등 작업 순서를 고민하게 된다. ICE 아메리카노 재료(원두·얼음·물)와 플라스틱 컵 부담도 커진다.
- 새 씬 오브젝트가 없어 Cafe 씬 재빌드는 필요 없다. 이미 있는 `GameBalance.asset` 에는 새 필드 기본값이 적용되고 Inspector 에서 조절한다.
- 수치는 docs/GAME_DATA.md 9장에 있고 모두 임시다.

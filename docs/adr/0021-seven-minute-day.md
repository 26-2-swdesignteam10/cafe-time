# ADR-0021: 하루 영업을 약 7분으로 더 줄인다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-014

## 맥락

ADR-0020 에서 하루를 약 10분(게임 1시간 = 실제 50초)으로 줄였다. 사용자가 하루 플레이 시간을 더 줄이자고 했다 (2026-11-12, "하루 플레이타임을 줄이자 7분?").

## 결정

게임 1시간 = 실제 35초로 바꾼다 (`GameBalance.secondsPerGameHour`). 영업 09:00~21:00 = 실제 420초. ADR-0020 의 하루 시간 부분만 대체하고, DAY별 난이도 표는 그대로 쓴다.

## 검토한 대안

- 하루 10분 유지 (ADR-0020): 사용자가 더 짧게 원했다.

## 결과

- 손님 입장 간격은 실제 초라서 하루에 오는 손님도 약 30% 줄어든다 (DAY 1 약 6일행, DAY 15 약 15일행). 너무 한산하면 DAY별 표의 입장 간격을 줄인다.
- 이미 만든 `GameBalance.asset` 은 Inspector 에서 `secondsPerGameHour` 를 35 로 바꿔야 한다.

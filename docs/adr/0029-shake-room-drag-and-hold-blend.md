# ADR-0029: 쉐이크 제조실은 끌어 넣고 누르고 있는 동안 갈며, 포스기는 실제 단말기 화풍으로 바꾼다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-026, SFR-052, SFR-053, SFR-054, SFR-055

## 맥락

쉐이크 제조실은 도트 패널 위에서 원액 아이콘 클릭, 우유 칸 누르고 있기, '갈기' 한 번 누르면 정해진 시간 뒤 완료되는 방식이었고, 포스기는 검은 테두리 안 빈 칸 두 개와 도트 버튼이었다.
사용자 요청 (2026-11-12): "쉐이크 제조실도 디자인 밤티고 얘도 음료제조실처럼 역동적이었으면 좋겠어 그리고 포스기도 디자인 바꾸어줘".
질문에 대한 사용자 선택: 재료는 끌어서 넣기, 갈기는 누르고 있는 동안, 컵에 옮기기는 붓기 버튼 + 애니메이션, 포스기는 실제 카페 포스기.

## 결정

### 쉐이크 제조실 (Art/UI/ShakeRoom, 일러스트)
- 원액 통 5개에 국자가 꽂혀 있다. 국자를 믹서기로 끌어 놓으면 1회분(`AmountPerClick`, 50g) 투입.
- 우유 팩을 믹서기 위로 끌고 가 있는 동안 팩이 기울어져 붓는다 (`pourPerSecond`). 그림은 DrinkTools 의 우유 팩·줄기를 재사용.
- 얼음은 기존처럼 손의 얼음 스쿱을 용기에 끌어 놓는다.
- 용기 안 내용물이 무게에 따라 차오른다 (가장 많이 넣은 원액의 그림. 원액이 없으면 우유·얼음 그림).
- **갈기는 버튼을 누르고 있는 동안만** 진행된다. 떼면 멈추고 진행은 유지된다. 누르는 동안 믹서기가 흔들리고 뚜껑·소용돌이가 보이며, 진행에 따라 매끈한 스무디 그림으로 바뀐다. 갈기를 시작하면 재료를 더 넣을 수 없다 (SFR-053 그대로).
  - 그래서 "갈기는 화면을 닫아도 계속된다"는 이전 동작은 없어지고, 믹서기의 완료 아이콘(SFR-022)도 뜨지 않는다.
  - 갈기 시간 5초(`BlendSeconds`)는 누르고 있는 시간의 합이다.
- 붓기 버튼을 누르면 용기가 컵 위로 기울어져 맛 색깔의 줄기가 흐른 뒤 판정한다 (판정 규칙은 그대로).

### 포스기 (Art/UI/Pos, 일러스트)
- 터치스크린 단말기 화풍. 메뉴 버튼은 그림이 들어간 카드이며, 음료 그림은 Art/UI/DrinkResult 완성품 그림을 재사용한다 (디저트 3개는 Pos 폴더에 새로).
- 기능(탭, HOT/ICE, 주문 목록, 수량, 삭제, 취소, 결제, Enter 결제)은 바꾸지 않는다.

## 검토한 대안

- 재료 작업 창을 따로 여는 방식(음료 제조실과 같음): 사용자가 끌어서 넣기를 골랐다.
- 한 번 누르면 자동으로 갈기(기존): 사용자가 누르고 있는 방식을 골랐다.
- 용기를 끌어서 컵에 붓기: 사용자가 버튼 + 애니메이션을 골랐다.

## 결과

- 쉐이크 제조실에서 다른 일을 하며 기다리는 시간이 없어진다 (갈기 5초 동안 화면에 머문다).
- 원액 종류를 추가하면 원액 통·국자·내용물 그림과 빌더의 원액 표에 한 줄씩 더해야 한다.

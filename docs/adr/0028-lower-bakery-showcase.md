# ADR-0028: 손님은 아래쪽 큰 베이커리 진열대에서 직접 픽업한다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-012, SFR-024, SFR-026, SFR-056

## 맥락

사용자는 포스기 왼쪽 진열장 기능을 없애고, 손님이 화면 아래의 커다란 베이커리 진열장에서 물건을 가져오는 설정을 원했다. 현재 맵에는 아래쪽에 세로로 긴 빵 진열대 두 개가 있으나 장식 가구였고, 손님 픽업 지점은 포스기 왼쪽에 있었다.

## 결정

- 포스기 왼쪽 `디저트 진열장` 기기를 제거한다. 테두리·키 안내·재고 팝업 연결도 제거한다.
- 진열장 재고 팝업은 새 씬에서 생성하지 않는다. 재고는 오픈 준비 구매 화면에서 확인하며 별도 수동 배치·보충은 없다.
- 기존 아래쪽 빵 진열대 두 개의 그림·위치·충돌 영역은 유지하고, 사이 통로를 손님 픽업 위치로 사용한다. 기본 픽업 좌표는 (6, 4), 두 진열대의 중심 x는 4.3과 7.7이다.
- 베이커리를 고른 일행은 입구 아래쪽 통로(y=1.25) → 진열대 사이(x=6) → 픽업 위치 → 진열대 위쪽 통로(y=7.25) → 포스기 줄 순서로 이동한다. 일행은 같은 세로 통로에서 뒤따른다.
- 줄이 앞으로 당겨질 때도 진열대 사이에 있는 손님은 위쪽 통로를 먼저 거친다. 방문 도중 영업이 끝나면 아래쪽 통로로 돌아 나간다.
- 손님이 집을 때 재고 차감, 품절 처리, 이탈·환불 재고 복구, 품목·수량 대사와 수동 포스기 입력(ADR-0027), 베이커리 제조·서빙 제외는 유지한다.
- `CafeTime > Update Bakery Showcase` 메뉴는 현재 Cafe 씬에서 작은 진열장·팝업 제거와 픽업 위치만 갱신한다. Undo를 지원하며 변경 후 사용자가 씬을 저장한다. 전체 씬 빌더도 같은 설정을 생성한다.

## 검토한 대안

- 포스기 왼쪽 기기를 두고 상호작용만 끄기: 불필요한 작은 진열장이 남으므로 제거한다.
- 새 진열장을 추가하기: 사용자가 지정한 기존 아래쪽 가구를 그대로 사용한다.
- 픽업 위치에서 포스기로 직선 이동하기: 기존 가구의 충돌 영역을 관통하므로 통로를 거친다.

## 결과

ADR-0016의 아래쪽 빵 진열대가 장식 가구라는 부분과 ADR-0026의 픽업 위치·재고 팝업 부분을 대체한다. 승인된 ADR-0027의 수동 계산 방식은 유지한다. 기존 스크립트·그림 파일은 GUID 보존을 위해 삭제하지 않으며 씬 YAML은 직접 수정하지 않는다.

## Unity 확인 절차

1. Unity 6000.6.4f1에서 Play를 멈추고 Cafe 씬을 연다. `CafeTime > Update Bakery Showcase`를 실행하고 씬을 저장한다. 전체 씬 재빌드는 필요 없다.
2. 포스기 왼쪽 작은 진열장과 키 안내·상호작용이 사라지고, 아래쪽 큰 진열대는 그대로인지 확인한다.
3. 베이커리를 고른 손님이 아래쪽 진열대 사이에 들른 뒤 위쪽 통로로 돌아 포스기에 줄 서는지 확인한다. 여러 명 일행과 긴 줄에서도 진열대를 가로지르지 않는지 확인한다.
4. 픽업 도중 줄이 당겨지는 경우와 영업 종료 시 퇴장 동선을 확인한다.
5. 손님 대사를 보고 베이커리를 수동 입력하고 결제할 수 있는지, 구매·픽업·환불에 따른 재고 변화가 유지되는지 확인한다.

# ADR-0055: 영업은 21시 마감, 20시 입장 마감으로 하고, 남은 손님을 다 보내야 하루가 끝나며 마감을 넘기면 감점한다

- 상태: 승인
- 날짜: 2026-11-26
- 관련 명세: SFR-014, SFR-057, SFR-068

## 맥락

ADR-0044 는 영업 종료를 18:00, 입장 마감을 17:30 으로 당겼다. 18:00 이 되면 남은 손님의 주문을 환불하고, 손님 이탈 감점을 준 뒤 바로 하루를 끝냈다.

사용자가 2026-11-26 다음과 같이 요청했다. "시간을 21시까지 늘리고 손님 마감은 20시까지 하고 손님을 다 끝내야 하루 종료되도록 하자. 마감시간을 넘으면 감점이 되는 식." 세부 사항은 사용자가 골랐다.

- 시간 배율 35초는 그대로 둔다. 마감 시각까지 하루 약 7분이다.
- 감점은 넘긴 시간만큼 준다.
- 강제 종료 상한은 두지 않는다.

## 결정

- 입장 마감은 20:00(`entryCloseHour` = 20), 마감 시각은 21:00(`closeHour` = 21)이다. 시간 배율은 게임 1시간 = 실제 35초를 유지한다.
- 20:00 이후 새 손님(단골·러시 포함)은 들어오지 않는다. 손님 일행과 대기 주문이 모두 없어지면 그 시각에 영업을 끝낸다. 21:00 전에 끝날 수도 있다.
- 21:00 이 지나도 시계는 계속 가고 영업도 계속된다. 시계 글자는 빨간색으로 바뀐다. 상한은 없다. 손님은 인내심이 다하면 평소처럼 떠난다(환불 + 손님 이탈 감점).
- 영업을 끝낸 시각이 21:00 을 넘었으면, 넘긴 게임 시간(분, 올림)을 `DayResult.overtimeMinutes` 에 기록한다. 득점 결과에서 10분마다 `penaltyOvertimePer10Min`(임시 30점)을 감점한다. 1분만 넘겨도 10분으로 친다.
- 득점 결과 화면 감점 사항에 6번째 줄 '마감 초과'(n분)를 추가한다. 6줄이 구분선 위에 들어가도록 줄 간격을 42 → 38 로 줄인다. 아이콘·글자 그림(`IconOvertime.png`, `LabelOvertime.png`)은 Codex 로 만든다.
- ADR-0044 는 이 ADR 로 대체한다.

## 검토한 대안

- 시간 배율을 26초로 줄여 하루 5분 유지: 사용자가 35초 유지를 골랐다.
- 21:00 을 넘기면 한 번만 고정 감점, 또는 21:00 에 남은 손님 수만큼 감점: 사용자가 넘긴 시간만큼 감점을 골랐다. 늦게 끝낼수록 손해라 서두를 이유가 생긴다.
- 22:00 강제 종료: 사용자가 상한 없음을 골랐다.

## 결과

- 마지막 손님을 빨리 보내는 것이 점수가 되어, 영업 막바지에 시간 압박이 생긴다.
- 하루가 약 5분 15초에서 7분 안팎으로 길어진다.
- 시간대 조명(노을)은 15:00 부터 마감 시각(21:00)까지 이어진다. 밤 그림은 따로 없다.
- 손님이 이상하게 남아 있는 버그가 생기면 하루가 끝나지 않는다. 상한을 두지 않았으므로 손님 동선 버그에 주의한다.

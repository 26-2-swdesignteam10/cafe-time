# ADR-0025: 청은 숟가락을 끌어 넣고 티백은 물 담긴 컵에 끌어 담근다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-046
- 대체: ADR-0024 의 청·티백 조작 부분

## 맥락

ADR-0024 에서 청과 티백도 클릭 1회로 넣었다. 사용자 요청 (2026-11-12): "딸기청, 유자청 등은 숟가락으로 직접 드래그하는 효과가 있었으면 좋겠다. 티백은 물에 담그는 느낌." 재료 작업 창 전체 크기도 더 키워 달라고 했다.

## 결정

- **청**: 병에 꽂힌 숟가락을 잡아 끌면 청이 떠진 숟가락이 마우스를 따라오고, 컵 위에 놓으면 숟가락을 기울여 1숟가락(`syrupPerClick`)이 들어간다. 컵 밖에 놓으면 그냥 돌아간다.
- **티백**: 상자에서 티백을 끌어 컵 위에 놓으면 물에 잠기며 찻물이 번지는 애니메이션(1회) 후 티백 덧그림이 남는다. 투입량은 기존과 같다(1개).
- **물이 있어야 티백**: 컵에 뜨거운 물·차가운 물이 없으면 넣지 않고 '물을 먼저 받아 주세요' 안내를 띄운다 (사용자 선택).
- **창 크기**: 재료 작업 창을 1.3배(약 1430x910, 음료 제조실 창과 비슷)로 키운다. 그림 좌표는 그대로 두고 창 전체를 확대한다.

## 검토한 대안

- 청을 컵 위에서 저어야 들어가게: 조작이 늘어 끌기 1번 = 1숟가락을 골랐다.
- 티백을 위아래로 몇 번 담가야 우러나게: 덜 우린 경우의 판정까지 정해야 해서, 끌어 넣으면 연출로 우러나는 쪽을 골랐다.
- 빈 컵에도 티백 허용: 사용자가 물이 있어야 넣는 쪽을 골랐다.

## 결과

- 펌프(시럽·연유)와 붓기(우유·탄산수) 조작은 ADR-0024 그대로다.
- 티백을 넣은 뒤 물을 더 받는 순서는 여전히 가능하다 (레시피는 완성 때 판정).

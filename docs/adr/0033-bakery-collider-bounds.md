# ADR-0033: 빵 진열대 충돌 영역을 현재 그림 크기에 맞춘다

- 상태: 제안
- 날짜: 2026-11-12
- 관련 명세: SFR-012, SFR-020, SFR-056

## 맥락

사용자는 진열대 Y를 2.5로 옮기고 그림의 세로 크기도 줄인 뒤 위쪽의 보이지 않는 벽 때문에 지나가지 못한다고 보고했다. 기존 빌더는 진열대 그림과 별개로 1.9×5.06칸의 고정 BoxCollider2D를 만들었다. PC에서 변경한 씬은 이 환경에 없어 실제 충돌 위치는 Unity에서 확인해야 한다.

## 결정

- 빵 진열대 Collider는 고정 크기 대신 현재 SpriteRenderer의 로컬 표시 영역에 맞춘다. Simple 그림은 투명 여백을 제외한 스프라이트 메시 범위, Sliced/Tiled는 현재 localBounds를 사용한다.
- `CafeTime > Fix Bakery Colliders`는 열린 Cafe 씬에서 진열대의 위치·스케일·표시 크기를 유지하고 BoxCollider2D의 Size와 Offset을 갱신한다. Collider가 없으면 추가한다. Undo를 지원하고 사용자가 씬을 저장한다.
- 진열대 두 개가 발견되면 두 그림 중심 사이로 손님 픽업 지점도 갱신한다.
- 전체 빌더에서도 고정 크기 Collider 생성을 없애며 기본 진열대 Y는 사용자 요청한 2.5를 사용한다. 기존 씬에서 줄여 둔 그림을 보존하려면 전체 재빌드 대신 수정 메뉴를 사용한다.

## 검토한 대안

- 충돌을 완전히 제거: 플레이어가 진열대 몸체까지 통과하므로 채택하지 않는다.
- Collider 높이를 임의의 새 상수로 변경: 사용자가 실제로 설정한 그림 높이와 다시 어긋날 수 있다.

## 결과

진열대 이동·그림 크기 변경 후 남은 충돌 범위를 에디터에서 다시 맞출 수 있다. 실제 Unity 화면에서 충돌 원인이 해당 BoxCollider인지, 그림 위쪽을 지나갈 수 있는지는 확인이 필요하다.

## Unity 확인 절차

1. PC에서 수정 중인 씬을 저장하고 Git 변경을 보존한 뒤 최신 브랜치를 받는다.
2. Play를 멈추고 Cafe 씬에서 `CafeTime > Fix Bakery Colliders`를 실행한다. 현재 Y=2.5와 줄인 그림 크기가 유지되는지 확인한다.
3. Scene 뷰의 Gizmos 또는 Collider 편집으로 충돌 영역이 현재 그림과 맞는지 확인한다. Play에서 위쪽 빈 공간을 통과하되 진열대 몸체는 통과하지 않는지 확인한다.
4. 손님이 현재 진열대 사이에서 픽업하는지 확인하고 씬을 저장한다. 이전 `Update Bakery Showcase` 메뉴를 다시 실행해 픽업 위치가 초기화됐다면 이 수정 메뉴를 마지막으로 실행한다.

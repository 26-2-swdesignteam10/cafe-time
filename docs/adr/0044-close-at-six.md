# ADR-0044: 영업 종료를 18:00, 입장 마감을 17:30으로 당긴다

- 상태: 대체됨 (ADR-0055)
- 날짜: 2026-11-18
- 관련 명세: SFR-014

## 맥락

명세서는 영업 시간을 09:00 ~ 21:00, 입장 마감을 20:00으로 정했다. 사용자가 2026-11-18 "21시 종료인거를 18시 종료로 바꾸어줘"라고 요청했다.
같이 확인해 보니 `GameBalance.asset` 의 시간 배율이 처음 만든 값(게임 1시간 = 실제 120초) 그대로여서, 승인된 ADR-0021(35초)이 실제 게임에 반영되지 않아 하루가 약 24분 걸리고 있었다.

## 결정

- 영업 종료를 18:00으로 당긴다 (`GameBalance.closeHour` = 18).
- 입장 마감은 사용자가 고른 17:30으로 한다. 30분 단위를 쓸 수 있도록 `entryCloseHour` 를 실수(시 단위, 17.5)로 바꾼다.
- 시간 배율은 ADR-0021 대로 게임 1시간 = 실제 35초를 쓴다 (사용자 확인). 하루 영업은 9시간 = 실제 약 5분 15초.
- 기존 에셋은 `CafeTime > Create Game Balance` 를 실행하면 예전 값(120초, 20시, 21시)일 때만 새 값으로 바뀐다.

## 검토한 대안

- 입장 마감 17:00 (종료 1시간 전, 기존 간격 유지): 사용자가 17:30을 골랐다.
- 입장 마감 없음: 사용자가 고르지 않았다.
- 시간 배율 47초(하루 약 7분 유지) 또는 120초 유지: 사용자가 35초를 골랐다.

## 결과

- 하루가 짧아져 하루에 오는 손님 수가 ADR-0021 때보다 약 25% 줄어든다. 한산하면 DAY별 난이도 표의 입장 간격을 줄인다.
- ADR-0021 의 "하루 약 7분"은 이 결정으로 약 5분 15초가 된다. 시간 배율 결정은 그대로 유효하다.

# ADR-0029: 행주 걸이를 오른쪽으로 옮기고 기존 받침대 한 칸을 제거한다

- 상태: 승인
- 날짜: 2026-11-12
- 관련 명세: SFR-012, SFR-020, SFR-066

## 맥락

작은 진열장을 제거한 뒤 빈자리가 생겼다. 사용자는 “행주 걸이를 오른쪽으로 한 칸 옮기고 기존 행주 걸이가 있던 칸은 없애줘”라고 확정했다.

## 결정

- 행주 걸이를 x=2.5에서 x=3.5로 한 칸 옮긴다. 높이·그림·상호작용·청소 기능은 유지한다.
- 기존 행주 걸이 아래의 앞쪽 카운터 타일 (2, 8)을 제거한다. 앞쪽 카운터는 x3~9가 되고 x1~2는 통로로 남는다.
- 포스기·픽업대 위치와 손님 동선은 유지한다.
- 전체 씬 빌더와 `CafeTime > Update Bakery Showcase` 메뉴에 같은 배치를 반영한다. 기존 씬에서는 이 메뉴를 다시 실행하면 된다.
- 업데이트는 절대 좌표를 사용해 여러 번 실행해도 이동·축소가 누적되지 않는다. 카운터 그림과 해당 충돌도 함께 제거하며 Undo를 지원한다.

## 검토한 대안

- 행주 걸이만 옮기고 받침대는 유지: 기존 행주 걸이가 있던 칸도 없애려는 사용자 요청과 맞지 않는다.
- 포스기나 픽업대까지 이동: 요청 범위가 아니므로 유지한다.

## 결과

작은 진열장 자리에는 행주 걸이가 들어가고, 카운터 왼쪽 통로는 한 칸 넓어진다. 기존 씬 YAML을 직접 편집하지 않고 Unity 메뉴로 적용한 뒤 저장한다.

## Unity 확인 절차

1. Play를 멈추고 Cafe 씬에서 `CafeTime > Update Bakery Showcase`를 실행한 뒤 씬을 저장한다.
2. 행주 걸이가 작은 진열장이 있던 위치로 한 칸 이동하고, 기존 행주 걸이 아래 받침대가 사라졌는지 확인한다.
3. 비워진 칸을 플레이어가 통과하고, 이동한 행주 걸이에서는 기존처럼 행주를 가져갈 수 있는지 확인한다.
4. 메뉴를 다시 실행해도 배치가 그대로인지 확인한다. Undo로 이동·타일 제거를 함께 되돌릴 수 있는지도 확인한다.

# ADR-0006: UI 씬·프리팹의 초기 배치는 에디터 빌더 스크립트로 만든다

- 상태: 승인
- 날짜: 2026-10-29

## 맥락

UI 배치 작업 일부를 AI 도구로 진행하는데, AI는 Unity 에디터를 직접 조작할 수 없다.
씬·프리팹 YAML을 손으로 쓰면 GUID·fileID 오류가 나기 쉽다.

## 결정

- 화면의 초기 구성은 `Assets/_Project/Editor/<화면>Builder.cs` 의 메뉴 명령(`CafeTime/Build ...`)으로 생성한다.
- 빌더는 **최초 생성용**이다. 다시 실행하면 에디터에서 수정한 내용을 덮어쓰므로, 생성 이후 수정은 씬·프리팹에서 직접 한다.
- 빌더 안에서 컴포넌트의 `[SerializeField]` 연결까지 처리해 생성 직후 Play 가능한 상태로 만든다.

## 검토한 대안

- 씬·프리팹 YAML 직접 작성: 참조 오류 위험이 크다.
- 런타임에 코드로 UI 생성: Inspector에서 위치·크기를 조정할 수 없어 디자인 수정이 어렵다.

## 결과

- 빌더가 덮어쓴다는 사실을 README의 에디터 도구 항목에 명시한다.
- 빌더 코드는 `Editor` 폴더에 있어 빌드에 포함되지 않는다.

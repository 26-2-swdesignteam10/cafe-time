# 게임 데이터

메뉴, 레시피, 가격, 시간 등 게임 수치를 모아 두는 문서다. 명세서에서 "추후 결정"으로 남은 값도 여기서 관리한다.

- 런타임 값은 `Assets/_Project/Resources/GameBalance.asset` 또는 각 컴포넌트의 `[SerializeField]` 에 있다. **수치를 바꾸면 에셋과 이 문서를 같은 PR에서 함께 고친다.**
- 상태: **확정**(명세서에 정해진 값) / **임시**(플레이 테스트용, 바뀔 수 있음) / **미정**(아직 값 없음)
- 값을 정하거나 바꾸면 상태를 갱신한다. 수치를 정하는 방식 자체(공식, 구조)가 바뀌면 ADR도 쓴다.

## 4. 메뉴와 레시피

재료 선반 구성(SFR-044, 052)에서 만들 수 있는 메뉴를 뽑은 **초안**이다. 메뉴 구성, 레시피 정량, 등급 허용 오차는 미정이고, 판매가는 영업 루프 테스트용 임시값이다(SFR-026, 051). 값은 `GameBalance.menus` 에 있다.

베이커리는 총 **8종**이다 (ADR-0026). 손님이 입장 후 화면 아래쪽 큰 빵 진열대 사이에 들러 재고가 있는 품목을 직접 집고, 위쪽 통로를 거쳐 포스기로 간다 (ADR-0028). 포스기 왼쪽 작은 진열장과 재고 팝업은 제거하며, 구매한 재고가 별도 배치 없이 아래쪽 진열대 재고로 연결된다. 집을 때 재고를 차감한다. 손님이 가져온 베이커리의 품목·수량을 말하면 플레이어가 포스기에 직접 입력하고 입력한 내역대로 계산한다 (ADR-0027). 포스기를 열 때 자동 등록하지 않으며 추가·수량 변경·삭제·취소가 가능하다. 결제 시에는 재고를 다시 차감하지 않는다. 플레이어는 베이커리를 제조하거나 픽업대에 올리지 않는다. 결제 전 이탈 또는 음료 미서빙 환불 시 베이커리도 반납 처리한다. 기존 품목의 id와 가격은 유지하며 신규 5종 가격은 사용자 요청대로 임시값이다. 기존 밸런스 에셋에는 누락된 품목만 추가하고, 기존 저장의 재고는 보존한다. 에셋 저장은 Unity의 `CafeTime > Create Game Balance` 메뉴를 사용한다.

위 표의 "레시피 미정"은 아래 **임시 레시피**로 채웠다 (`GameBalance.recipes`, ADR-0014). 샷·얼음·티백은 개수, 나머지는 g. ICE 는 모두 얼음 1스쿱이 더 들어간다.

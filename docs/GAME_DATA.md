# 게임 데이터

메뉴, 레시피, 가격, 시간 등 게임 수치를 모아 두는 문서다. 명세서에서 "추후 결정"으로 남은 값도 여기서 관리한다.

- 런타임 값은 `Assets/_Project/Resources/GameBalance.asset` 또는 각 컴포넌트의 `[SerializeField]` 에 있다. **수치를 바꾸면 에셋과 이 문서를 같은 PR에서 함께 고친다.**
- 상태: **확정**(명세서에 정해진 값) / **임시**(플레이 테스트용, 바뀔 수 있음) / **미정**(아직 값 없음)
- 값을 정하거나 바꾸면 상태를 갱신한다. 수치를 정하는 방식 자체(공식, 구조)가 바뀌면 ADR도 쓴다.
